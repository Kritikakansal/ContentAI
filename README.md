# ✨ ContentAI

An AI-powered content creation and improvement platform built with Python, Streamlit, and Google Gemini.

## 🚀 Overview

ContentAI helps users create platform-ready content and improve existing content using generative AI.

The application allows users to select the type of content, define their audience and preferred style, and generate customized content within seconds.

## ✨ Features

### Content Generation
- LinkedIn Posts
- Instagram Captions
- Professional Emails
- Blog Outlines

### Customization
- Target audience
- Tone selection
- Content length
- Language selection
- Emoji style

### Content Improvement
Users can paste existing content and improve it for:
- Professional writing
- Engagement
- Conciseness
- Grammar and clarity
- LinkedIn
- Instagram
- Email

### Additional Features
- AI-generated content using Google Gemini
- Word count
- Character count
- Download generated content
- Input validation
- Error handling
- Clean and responsive interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI Python SDK
- python-dotenv
